
# Shiro

Shiro is a shell written in C, heavily inspired by the [Suckless Philosophy](https://suckless.org/philosophy/) 

> [!WARNING]  
> !! shiro is still in development and alpha
## Run Locally

Clone the project

```bash
  git clone https://git.veradec.xyz/shiro.git
```

Go to the project directory

```bash
  cd shiro
```

Compile source code to binary

```bash
  gcc shiro.c -o shiro
```

Run the Shell

```bash
  ./shiro
```

## FAQ

#### is shiro *nix standard compliant? 

Shiro is a project that is still under development and it intends to be compliant with the nix standards

#### Where is the config file?

the config file is, `shiro.h` which when changed will need to be recompiled again, hot-reloading is a feature that is under discussion for future development
